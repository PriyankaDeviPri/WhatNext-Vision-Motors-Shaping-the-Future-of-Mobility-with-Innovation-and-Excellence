# 🚗 WhatNext Vision Motors – Salesforce CRM

## 📌 Project Overview

**WhatNext Vision Motors** is a **Salesforce-based CRM solution** designed to modernize vehicle ordering and dealership management.

The system automates vehicle order placement, stock validation, dealer assignment, test-drive reminders, and order status updates. It replaces manual and disconnected processes with a centralized Salesforce platform.

## 🎯 Objectives

- Automate vehicle ordering and stock management
- Validate vehicle availability before order confirmation
- Assign orders to the nearest dealer
- Automate test-drive reminders
- Track order status dynamically
- Provide real-time reports and dashboards
- Reduce manual intervention and improve operational efficiency

## ⚙️ Key Features

### 1. Stock Validation
The system checks vehicle availability before processing an order. Orders for unavailable vehicles are prevented or kept in a pending state.

### 2. Automated Dealer Assignment
Vehicle orders are automatically assigned to the appropriate dealer based on customer location.

### 3. Test Drive Scheduling
Customers can schedule test drives, and automated reminders can be sent before the scheduled appointment.

### 4. Apex Automation
Apex Triggers perform important vehicle-order operations and business validations.

### 5. Batch Apex
Batch processing handles pending vehicle orders and supports automatic stock-related updates.

### 6. Scheduled Apex
Scheduled Apex enables automated vehicle-order processing at predefined intervals.

### 7. Reports & Dashboards
Reports and dashboards provide visibility into order status, dealer performance, sales information, and operational activities.
